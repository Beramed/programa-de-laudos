# Programa de Laudos de Ultrassom

Montador de laudos prontos: escolha o tipo de exame e os achados — o texto é montado automaticamente para copiar ou imprimir.

## Exames incluídos

- Abdome Total
- Abdome Superior
- Tireoide
- Pélvica (via abdominal)
- Mamas
- Aparelho Urinário
- Obstétrico 1º Trimestre

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
